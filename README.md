Campus Gigs – Student Freelancing Marketplace

A full-stack web application and relational database system built to connect university students for campus-based freelancing gigs, services, and bookings.

## Database & Backend Architecture
* **Relational Database (SQL):** Structured database schema featuring normalized tables for users, service listings, bookings, categories, and reviews.
* **Server-Side API & Logic (PHP):** Custom backend endpoints (`db.php`, `get_services.php`, `get_bookings.php`, `get_reviews.php`) handling secure database connections and data retrieval.
* **Features:** End-to-end management of client-freelancer matching, service category browsing, and review tracking.

## Tech Stack
* **Database:** MySQL / SQL
* **Backend:** PHP, Apache
* **Frontend/UI:** HTML/CSS/JS integration via PHP views
